## How to Choose a Template

| Article Type | Use Template | Examples |
|---|---|---|
| "How do I use this feature?" | **Template 1: Feature Guide / How-To** | Meeting Prep How-To, Content Sharing, RFP Workflow |
| "What is this feature?" | **Template 2: User Overview / Concept** | AI assistant Overview, Template Hub, Digital Sales Rooms Introduction |
| "Walk me through this workflow step-by-step" | **Template 3: Step-by-Step Workflow** | How to Submit an RFP, How to Request Verification, How to Share Content |
| "How does this work on [platform]?" | **Template 4: Platform-Specific** | Meeting Prep on Chrome Extension, AI assistant in Slack, Mobile App Features |
| "Show me examples and best practices" | **Template 5: Use Case / Prompt Guide** | AI assistant Use Cases, RFP Best Practices, Effective Prompts |
