# Evidence Rules

## Fundamental scoring rules
- Evidence standard. Score only what is explicitly stated in the transcript.
- No inference. If you have to assume or interpret then the score for that criterion is zero.
- Direct quotes required. Every awarded point must include a supporting quote.
- This call only. Prior conversations count only if referenced explicitly in this call.
- Agreement does not count. Rep statement plus buyer yeah does not earn a point.

## Tie break policy
- If two adjacent scores fit choose the lower score unless all required elements are clearly met.
- Perfect scores are rare. Award maximum only when every sub requirement is satisfied.

## Quote formatting
- Use short verbatim quotes.
- Include speaker label in the quote attribution.
- If timestamps exist include them.

## What to do when evidence is missing
- Write Insufficient evidence.
- Give a specific question the rep should ask next time to capture it.
