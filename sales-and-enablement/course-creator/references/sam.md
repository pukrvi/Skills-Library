# SAM

## What it is

SAM, or Successive Approximation Model, is an iterative design method. It favors rapid prototypes, feedback, revision, and staged improvement.

## How Course Creator uses it

Use SAM as the iteration loop, especially when the user needs quick launch readiness.

| SAM behavior | Course Creator behavior |
| --- | --- |
| Prototype quickly | Draft course map and one sample module before writing everything |
| Review early | Ask the user to approve stage outputs |
| Iterate | Adjust objectives, module sequence, lessons, and assessments |
| Improve after launch | Add revision recommendations based on learner feedback and outcomes |

## Use when

- The course is needed quickly.
- Source material is incomplete.
- Stakeholders need to review before final development.
- Product, messaging, or process content may change.

## Self-paced rule

SAM can support rapid course development, but it must not create workshops or live sessions in this skill.

## Output example

```markdown
## SAM iteration loop

Prototype 1: Course map plus Module 1 sample lesson.
Review checkpoint: Confirm audience, difficulty, and assessment level.
Revision trigger: If the final assessment feels too hard, adjust lesson practice before reducing the standard.
Post-launch iteration: Use feedback form responses to revise unclear lessons first.
```
