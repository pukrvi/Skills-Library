# Dick and Carey Systems Approach

## What it is

Dick and Carey treats instruction as a system. Goals, learners, objectives, assessments, strategy, materials, and evaluation must align.

## How Course Creator uses it

Use Dick and Carey as the alignment checker.

| Component | Course Creator output |
| --- | --- |
| Instructional goal | Business and learner goal |
| Instructional analysis | Behavior map and prerequisite skills |
| Entry behaviors | Learner profile and assumptions |
| Performance objectives | Module and lesson objectives |
| Assessment instruments | Knowledge checks, graded assessments, rubrics |
| Instructional strategy | Module sequence and lesson framework |
| Instructional materials | Lessons, content blocks, scenarios |
| Formative evaluation | Stage evals and user checkpoints |
| Summative evaluation | Final measurement plan |

## Use when

- Building certification.
- Creating a graded assessment.
- Ensuring assessments test what the lessons teach.
- Preventing disconnected modules.

## Output example

```markdown
## Alignment check

Business goal: Improve renewal risk discovery.
Learner behavior: Identify risk signals and ask impact questions.
Lesson objective: Recognize three risk categories and ask two follow-up questions.
Knowledge check: Match risk signals to risk categories.
Assessment: Given a renewal scenario, select the best discovery response and explain why.
```
