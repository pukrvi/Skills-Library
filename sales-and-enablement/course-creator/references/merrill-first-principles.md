# Merrill's First Principles

## What it is

Merrill says learning works best when learners solve real problems, activate prior knowledge, see demonstrations, apply the skill, and integrate it into real work.

## How Course Creator uses it

Use Merrill when the course needs behavior change, not just knowledge transfer.

| Principle | Self-paced sales training application |
| --- | --- |
| Problem-centered | Start with a realistic buyer or account problem |
| Activation | Ask what the learner already does today |
| Demonstration | Show a strong example, model response, or worked example |
| Application | Have the learner choose, write, record, sort, match, or diagnose |
| Integration | Ask the learner to apply the idea to their own account or workflow |

## Use when

- Teaching discovery, objection handling, negotiation, demos, account planning, or CSM conversations.
- Creating applied knowledge checks.
- Creating pitch or free response assessments.

## Output example

```markdown
## Merrill-based activity

Problem: The prospect says the project has no budget this quarter.
Activation: Recall the last time budget blocked a deal.
Demonstration: Show a model response that uncovers business impact.
Application: Select the best next question from four options.
Integration: Write one question you will use in your next live opportunity.
```
