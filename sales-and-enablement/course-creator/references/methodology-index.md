# Methodology decision index

Use this table to choose the right methodology mix without overwhelming the user.

| Need | Primary method | Secondary method | Use in output |
| --- | --- | --- | --- |
| Understand problem and audience | ADDIE Analysis | Kemp | Course brief and constraints |
| Tie learning to revenue or business outcomes | Action Mapping | Dick and Carey | Behavior map and success metrics |
| Build full course structure | ADDIE Design | Dick and Carey | Course map, modules, sequence |
| Adapt to constraints | Kemp | SAM | Duration, learner level, source limits |
| Build a practical lesson | Tell-Show-Do-Apply | Gagne | Lesson plan and content blocks |
| Create scenario practice | CCAF | Merrill | Knowledge checks and self-paced application |
| Build skill transfer | Merrill | CCAF | Problem, demonstration, application, integration |
| Build graded assessment | Bloom | Dick and Carey | Assessment questions and rubric |
| Rapidly iterate | SAM | Kirkpatrick | Revision loop and pilot feedback |
| Reinforce learning | Microlearning | 70-20-10 | Recaps, follow-up drills, job aids |
| Measure impact | Kirkpatrick | Action Mapping | Behavior and outcome measurement |

## Default selections

- Use ADDIE as the macro course design operating system.
- Use SAM as the iteration loop, not as the main structure for enterprise courses.
- Use Dick and Carey as the alignment check.
- Use Kemp to adapt the design to learner constraints.
- Use Tell-Show-Do-Apply for most self-paced sales lessons.
- Use Gagne when lessons need a more structured flow.
- Use Merrill and CCAF when the lesson must change behavior.
- Use Bloom and Dick and Carey for graded assessments.
