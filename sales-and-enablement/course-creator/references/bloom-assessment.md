# Bloom for assessment design

## What it is

Bloom's Taxonomy helps classify learning depth. Use it to avoid assessments that only test recall when the course goal requires judgment or application.

## Levels for course design

| Level | Sales training example | LMS question fit |
| --- | --- | --- |
| Remember | Define a term | Single select, flip card knowledge check |
| Understand | Explain a concept | Single select, matching |
| Apply | Use a talk track in a scenario | Scenario single select, free response |
| Analyze | Diagnose what is wrong in a deal | Sorting, matching, free response |
| Evaluate | Choose the best strategy and justify it | Free response, pitch, scenario assessment |
| Create | Build an account plan or response | Free response, pitch, file upload if supported |

## How Course Creator uses it

Use Bloom when designing graded assessments. The assessment level must match the desired behavior.

## Rule of thumb

- Knowledge-heavy course: Use mostly remember, understand, and apply.
- Skill course: Use mostly apply, analyze, and evaluate.
- Certification: Include at least one apply or analyze assessment.

## Output example

```markdown
## Assessment depth

Objective: Handle a budget objection.
Bloom level: Apply and evaluate.
Assessment type: Scenario single select plus free response justification.
Why: The learner must choose a response and explain the reasoning.
```
