# CCAF

## What it is

CCAF stands for Context, Challenge, Activity, and Feedback. It is used to create meaningful interactions and scenario-based practice.

## How Course Creator uses it

Use CCAF for self-paced scenario practice, knowledge checks, and assessments.

| CCAF element | Course Creator output |
| --- | --- |
| Context | Buyer persona, account situation, deal stage, product context |
| Challenge | The decision the learner must make |
| Activity | Select, match, sort, write, record, or diagnose |
| Feedback | Explanation of why the answer works and what to improve |

## Use when

- A lesson needs realistic practice.
- The user asks for role plays but the course must remain self-paced.
- Knowledge checks need more than recall questions.
- Assessments should test judgment.

## LMS fit

- Use CCAF in knowledge checks for ungraded practice.
- Use CCAF in assessments for graded scenario questions.
- Use pitch assessment for recorded self-paced responses when appropriate.
- Use free response assessment for written diagnosis when appropriate.

## Output example

```markdown
## CCAF scenario

Context: You are speaking to a VP Sales who says enablement content is not being used.
Challenge: Choose the best next question.
Activity: Single select question with four options.
Feedback: The best answer quantifies the business impact before pitching a solution.
```
