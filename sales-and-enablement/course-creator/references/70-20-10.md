# 70-20-10 as optional post-course application lens

## What it is

70-20-10 is a workplace learning model that balances formal learning, social learning, and on-the-job application.

## How Course Creator uses it

Use this only as an optional post-course application lens. The course itself remains self-paced.

| Lens | Self-paced course adaptation |
| --- | --- |
| Formal learning | Lessons, knowledge checks, graded assessments |
| Social learning | Optional discussion prompt or peer review suggestion outside the course |
| On-the-job application | Learner-owned account task, job aid, or workflow prompt |

## Constraint

Do not turn this into live coaching, live manager sessions, or classroom training. If the user requests adoption support, create a separate post-course adoption plan and label it outside the self-paced LMS course.

## Output example

```markdown
## Optional post-course application

Formal: Learner completes the course.
Application: Learner uses the call-prep checklist on one upcoming meeting.
Optional social: Learner shares one takeaway in the team channel if the organization wants peer reinforcement.
```
