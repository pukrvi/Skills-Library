# Examples of methodology outputs

## ADDIE output

```markdown
Analysis: New AEs need to qualify enterprise opportunities more consistently.
Design: Four modules move from qualification concepts to applied deal judgment.
Development: Lessons, knowledge checks, and graded final assessment are created.
Implementation: Course is built in target LMS with sequential learning enabled.
Evaluation: Measure pass rate, feedback, behavior adoption, and pipeline conversion.
```

## SAM output

```markdown
Prototype: Build the course map and Module 1 first.
Feedback gate: Ask enablement to confirm difficulty and tone.
Iteration: Revise module sequence before generating all assessments.
Post-launch: Review feedback form responses after the first cohort.
```

## Action Mapping output

```markdown
Business goal: Improve demo-to-next-step conversion.
Learner action: Connect each demo moment to a buyer business problem.
Practice: Given a buyer scenario, select the most relevant demo proof point.
Content needed: Demo storyline, persona pains, proof points.
Metric: Assessment score and demo call behavior.
```

## Gagne output

```markdown
Attention: Start with a buyer pushback scenario.
Objective: Learner can respond with a value-based question.
Recall: Ask what they currently say.
Content: Teach the response pattern.
Guidance: Show weak and strong examples.
Practice: Ungraded scenario question.
Feedback: Explain the correct answer.
Assessment: Final graded scenario.
Retention: Recap and downloadable job aid.
```

## Merrill output

```markdown
Problem: A renewal champion goes silent.
Activation: Learner recalls the last stalled renewal.
Demonstration: Show a model re-engagement message.
Application: Learner writes a response.
Integration: Learner adapts it to one active account.
```

## CCAF output

```markdown
Context: VP Enablement says reps do not use content.
Challenge: Decide the best diagnostic question.
Activity: Single select knowledge check.
Feedback: The best answer identifies behavior before suggesting content.
```

## Tell-Show-Do-Apply output

```markdown
Tell: Explain the objection response framework.
Show: Provide a strong example answer.
Do: Let learner choose the next best response.
Apply: Ask learner to write one response for their territory.
```
