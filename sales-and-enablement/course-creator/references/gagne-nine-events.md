# Gagne's Nine Events of Instruction

## What it is

Gagne's Nine Events provide a structured lesson flow:

1. Gain attention
2. State the objective
3. Recall prior knowledge
4. Present content
5. Provide learning guidance
6. Elicit performance
7. Provide feedback
8. Assess performance
9. Enhance retention and transfer

## How Course Creator uses it

Use Gagne to structure self-paced lessons. Translate live events into asynchronous equivalents.

| Event | Self-paced course equivalent |
| --- | --- |
| Gain attention | Short scenario, data point, buyer problem, or lost-deal moment |
| State objective | Clear learner outcome at the top of the lesson |
| Recall prior knowledge | Reflection prompt or quick ungraded question |
| Present content | Rich text, video, document, or embedded source |
| Provide guidance | Examples, checklists, annotated talk tracks |
| Elicit performance | Knowledge check or scenario prompt |
| Provide feedback | Answer explanation or model response |
| Assess performance | Graded assessment, usually outside the lesson |
| Enhance retention | Recap, job aid, or spaced follow-up question |

## Use when

- A lesson needs strong flow and clarity.
- The learner is new to the topic.
- The course needs a consistent lesson structure.

## Output example

```markdown
## Lesson flow using Gagne

Attention: The buyer says, "We already have a tool for this."
Objective: Choose a response that reframes the problem without attacking the incumbent.
Recall: What do you usually ask when a buyer mentions an existing tool?
Content: Teach the three-part displacement response.
Practice: Choose the strongest response from four options.
Feedback: Explain why the best response creates curiosity.
Retention: Add the response pattern to the final job aid.
```
