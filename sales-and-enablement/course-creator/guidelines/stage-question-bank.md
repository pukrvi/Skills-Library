# Stage question bank

Use these questions stage by stage. Do not ask all questions at once. Select the smallest useful set for the current stage.

## Stage 1 questions: Training Intake Analyst

Ask:

1. What is the course topic?
2. Who is the target learner?
3. What business result should this course support?
4. What does the learner need to do differently after the course?
5. Do you have source material to use?
6. What duration or depth should the course have?

Options to offer:

```markdown
What type of course are we building?

1. New hire onboarding course [ADDIE, Kemp]
2. Product or messaging launch course [SAM, Microlearning]
3. Sales skill mastery course, such as discovery or objection handling [Action Mapping, Merrill]
4. Certification course with graded assessment [Dick and Carey, Bloom]
5. Process or policy training course [Gagne, Tell-Show-Do-Apply]
```

## Stage 2 questions: Performance Goal Mapper

Ask:

1. Which business metric should improve?
2. Which learner behavior most directly affects that metric?
3. What mistakes are learners making today?
4. What does good performance look like?
5. How will the team know the course worked?

Options to offer:

```markdown
Which success metric matters most?

1. Knowledge readiness, such as product or process understanding [Bloom]
2. Behavior change, such as better discovery or qualification [Action Mapping]
3. Certification pass rate [Dick and Carey, Bloom]
4. Business outcome, such as conversion, win rate, renewal risk, or ramp time [Kirkpatrick]
```

## Stage 3 questions: Course Architect

Ask:

1. Should the course be short, standard, or comprehensive?
2. Should modules follow the buyer journey, sales process, product areas, role tasks, or competency levels?
3. Should the final assessment be scenario-based, knowledge-based, pitch-based, or mixed?
4. Should sequential learning be enabled?
5. What category should the course use?

Options to offer:

```markdown
How should we structure modules?

1. Role task sequence [Kemp, Dick and Carey]
2. Sales process sequence [ADDIE Design, Action Mapping]
3. Product capability sequence [Gagne, Tell-Show-Do-Apply]
4. Competency progression from basic to advanced [Bloom, Dick and Carey]
5. Scenario progression from easy to hard [Merrill, CCAF]
```

## Stage 4 questions: Lesson Designer

Ask:

1. Should each lesson be concept-first, scenario-first, or example-first?
2. What source assets should be included in lessons?
3. Should lessons be mostly text, video, document-based, or mixed?
4. How much practice should each lesson include through knowledge checks?

Options to offer:

```markdown
Which lesson style should we use?

1. Tell, Show, Do, Apply for practical enablement [Tell-Show-Do-Apply]
2. Structured lesson flow with attention, objective, practice, and retention [Gagne]
3. Problem-first lesson using realistic learner challenges [Merrill]
4. Short focused micro-lessons [Microlearning]
```

## Stage 5 questions: Knowledge Check and Scenario Designer

Ask:

1. Should knowledge checks test recall, judgment, sequence, matching, or application?
2. Should scenarios use buyer personas, internal process cases, product use cases, or customer situations?
3. What feedback style should be used?

Options to offer:

```markdown
Which knowledge check pattern should we use?

1. Quick recall questions [Microlearning]
2. Scenario decision questions [CCAF]
3. Match concepts to examples [Bloom]
4. Sort steps in the right order [Gagne]
5. Flip cards for key terms or talk tracks [Microlearning]
```

## Stage 6 questions: Assessment Builder

Ask:

1. What should count toward pass or fail?
2. What passing percentage should be used?
3. Should the assessment be auto-graded, manually reviewed, or mixed?
4. Should retakes be allowed?
5. Should questions and answer options be randomized?
6. Are reviewers needed for free response or pitch questions?

Options to offer:

```markdown
Which assessment style should we use?

1. Auto-graded knowledge assessment [Bloom]
2. Scenario judgment assessment [CCAF, Bloom]
3. Written application assessment with manual review [Merrill, Dick and Carey]
4. Pitch assessment with manual reviewer rubric [Merrill, Bloom]
5. Mixed assessment with auto-graded and manual questions [Dick and Carey]
```

## Stage 7 questions: Reinforcement and Retention Planner

Ask:

1. Should reinforcement happen inside the course only or after completion too?
2. Should we include job aids?
3. Should we include spaced refresher prompts?
4. Should learners apply the course to their own account, customer, or task?

Options to offer:

```markdown
Which reinforcement pattern should we use?

1. In-course recaps after each module [Gagne]
2. Short post-course refreshers [Microlearning]
3. Learner-owned application task [Merrill, 70-20-10]
4. Iteration based on feedback form data [SAM, Kirkpatrick]
```

## Stage 8 questions: LMS Output Builder

Ask:

1. Do you want a blueprint only, or should I also prepare LMS tool calls?
2. Should the course be saved as draft or published after approval?
3. Should sequential learning be enabled?
4. Should content download be allowed?
5. Should certificates be enabled?
6. Who are the reviewers for manual questions?

Options to offer:

```markdown
What output should I produce?

1. Course blueprint only [ADDIE, LMS Output Logic]
2. Full course pack with all lessons, checks, assessments, and feedback [Dick and Carey, LMS Output Logic]
3. LMS build-ready JSON blueprint [LMS Output Logic]
4. LMS tool-call plan after blueprint approval [LMS Build Mode]
```

## Stage 9 questions: Quality Reviewer

Ask only if the final review finds a blocker.

Examples:

- The final module does not yet include a graded assessment. Should I add a scenario-based final assessment? [Dick and Carey, Bloom]
- The course includes a pitch question but no reviewers. Who should review it? [LMS Assessment Rules]
- The course has no feedback form. Should I enable Rating and Feedback and add these final feedback questions? [Kirkpatrick]
