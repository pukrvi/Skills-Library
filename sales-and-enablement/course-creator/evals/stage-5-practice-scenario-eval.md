# Stage 5 eval: Knowledge Check and Scenario Designer

## Required fields

| Check | Pass condition |
| --- | --- |
| Knowledge checks ungraded | Every knowledge check is marked ungraded |
| Supported types | Uses single select, multi select, matching, sorting, checklist, or flip card |
| Flip card rule | Flip cards appear only in knowledge checks |
| Scenario quality | Scenario has context, challenge, activity, and feedback when using CCAF |
| Feedback | Correct answers include explanation or model feedback |
| Alignment | Practice maps to lesson objective and learner behavior |

## Blocking issues

Ask clarifying questions if:

- A knowledge check is graded.
- A flip card is placed in an assessment.
- Scenario context is missing for a judgment-based question.
