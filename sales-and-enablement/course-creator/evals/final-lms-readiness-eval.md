# Final LMS readiness eval

## LMS readiness checklist

| Check | Pass condition |
| --- | --- |
| Course title | Present |
| Description | Present |
| Category | Selected or recommended |
| Modules | At least one module exists |
| Lessons | Lessons contain content blocks, not graded questions |
| Knowledge checks | Ungraded and use supported types |
| Assessments | Graded and use supported types |
| Final module | Contains final graded assessment |
| Feedback form | Last learner-facing step |
| Course settings | Passing percentage, retakes, sequential learning, rating and feedback addressed |
| Reviewers | Present when manual review is required |
| Publish approval | Explicit approval exists before publishing |

## Tool-call readiness

Before any LMS tool execution, confirm:

- The user approved the blueprint.
- Course category is available or a fallback category is selected.
- Manual reviewers are resolved if required.
- The course should be draft or published.
- Publishing has explicit approval if requested.

## Failed tool handling

If a tool call fails:

1. State what failed.
2. Do not assume the item was created.
3. Retrieve the course if possible.
4. Provide the gap and next corrective action.
