# Stage 6 eval: Assessment Builder

## Required fields

| Check | Pass condition |
| --- | --- |
| Assessments graded | Every assessment is marked graded |
| Supported types | Uses supported assessment types |
| Auto versus manual grading | Grading mode is identified |
| Manual review | Free response and pitch have reviewers and rubrics |
| Bloom alignment | Question difficulty matches objective |
| Passing criteria | Passing percentage is defined |
| Retake logic | Retake recommendation is included |
| Checklist warning | Checklist is avoided or user-approved if used in assessment |

## Blocking issues

Ask clarifying questions if:

- Free response or pitch is used with no reviewer.
- Passing percentage is missing for a certification course.
- The final assessment does not test the main performance goal.
- Checklist is used in a graded assessment without warning and approval.
