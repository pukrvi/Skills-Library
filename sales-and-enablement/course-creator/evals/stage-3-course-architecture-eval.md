# Stage 3 eval: Course Architect

## Required fields

| Check | Pass condition |
| --- | --- |
| Course map | Modules and lessons are sequenced logically |
| LMS hierarchy | Uses course, modules, lessons, knowledge checks, assessments |
| Module objectives | Every module has an objective |
| Assessment placement | Final module contains final graded assessment |
| Feedback placement | Feedback form is after final assessment |
| Self-paced | No live workshops or live facilitation |
| Duration | Estimated time exists |

## Blocking issues

Ask clarifying questions if:

- The final module does not include a graded assessment.
- The course map includes live sessions.
- The user needs certification but no graded assessment is planned.
- The module sequence does not match the learner journey.
