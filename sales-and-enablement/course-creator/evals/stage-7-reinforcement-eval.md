# Stage 7 eval: Reinforcement and Retention Planner

## Required fields

| Check | Pass condition |
| --- | --- |
| Self-paced reinforcement | Activities do not require live delivery |
| Recaps | Important modules include recap or retention support |
| Spaced practice | Post-course or in-course refreshers are recommended when useful |
| Application | Learner-owned application task is included where behavior change matters |
| Feedback loop | Feedback form data is used for iteration |

## Blocking issues

Ask clarifying questions if:

- Reinforcement requires live coaching inside the course.
- No retention strategy exists for a high-stakes course.
- Application tasks depend on unsupported LMS features without fallback.
