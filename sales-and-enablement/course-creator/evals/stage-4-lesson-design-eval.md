# Stage 4 eval: Lesson Designer

## Required fields

| Check | Pass condition |
| --- | --- |
| Lesson objective | Each lesson has one clear objective |
| Methodology | Each lesson uses Gagne, Merrill, Tell-Show-Do-Apply, or Microlearning |
| Content blocks | Content block types are LMS-compatible |
| Self-paced activity | Practice is asynchronous and self-contained |
| No graded questions in lessons | Graded assessment items are separate LMS entities |
| Examples | Lessons include concrete examples where useful |

## Blocking issues

Ask clarifying questions if:

- Lessons are just topic names with no objectives.
- Lessons include live discussion or facilitator steps.
- The required source content is missing and cannot be assumed.
