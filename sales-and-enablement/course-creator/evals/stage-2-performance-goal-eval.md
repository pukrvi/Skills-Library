# Stage 2 eval: Performance Goal Mapper

## Required fields

| Check | Pass condition |
| --- | --- |
| Business goal | Connected to course purpose |
| Observable behaviors | At least 2 observable learner actions |
| Current mistakes | Known or reasonably assumed |
| Practice implications | Each behavior has a practice path |
| Metrics | At least one learning metric and one business or behavior metric |

## Blocking issues

Ask clarifying questions if:

- The output only lists knowledge topics and no learner behaviors.
- The stated business goal does not match the learner audience.
- The course is supposed to certify skill but no performance standard exists.

## Quality bar

The stage passes only if a course designer can answer: What should learners do differently after the course?
