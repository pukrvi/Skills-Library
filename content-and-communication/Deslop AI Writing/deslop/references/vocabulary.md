# Vocabulary reference

Compiled August 2026. Re-check roughly every 18 months — vendors patch these and humans absorb them.

Match inflected forms. `delve` covers delving/delved/delves. `meticulous` covers meticulously. `leverage` covers leveraging/leveraged. Judge by context when a variant has a separate honest sense (`real` meaning factual is not the same as `real` as an empty intensifier).

---

## Tier 1A — always replace, and a cluster is evidence

Claimed to appear 5–20× more often in machine text than human text. Corroborated for the core set by corpus studies of 15M+ PubMed abstracts (Kobak et al., *Science Advances* 2025) and 2.4M full texts through July 2025 (Kousha & Thelwall, *Scientometrics* 2026), which measured delve +1,500%, underscore +1,000%, intricate +700%, meticulous +600% between 2022 and 2024.

## Tier 1B — always replace, but NOT authorship evidence

Wordiness and inflated formality. Fixing them is good writing regardless of who wrote the sentence. Measured against verified pre-2023 human prose, these fire at a meaningful rate on ordinary professional and formal writing. **In detect mode, report these separately and label them clearly.** Presenting a wordiness fix as evidence of machine authorship is the specific error this split exists to prevent.

| Replace | With |
|---|---|
| utilize | use |
| in order to | to |
| due to the fact that | because |
| serves as | is |
| features (verb) | has, includes |
| boasts | has |
| presents (inflated) | is, shows, gives |
| commence | start, begin |
| ascertain | find out, determine |
| endeavor | effort, attempt, try |
| prior to | before |
| in the event that | if |
| a number of | some, several, or a count |

## Tier 2 — flag when 2+ appear in the same paragraph

Legitimate on their own. Two or more together means the paragraph needs a rewrite.

empower · facilitate / facilitates · resonate / resonates with · encompass · catalyze · reimagine · galvanize · augment · illuminate · juxtapose · underpin / underpinnings · nuanced · ecosystem (metaphorical) · myriad · plethora · poised (to) · nascent · quintessential · overarching · transformation · quietly · deeply (only in significance collocations — "deeply integrated", "deeply committed", "deeply rooted"; "deeply nested" and "cares deeply" never count) · complexities · endeavor (noun) · milestone · metamorphosis

## Tier 3 — flag only at high density (~3%+ of total words)

Normal words. Only a problem when the text is saturated with them, which signals that vague praise replaced specifics.

| Word | What to do |
|---|---|
| significant / significantly | replace some with numbers, comparisons, examples |
| innovative / innovation | describe what's actually new |
| effective / effectively | say how, or cite a metric |
| dynamic / dynamics | name the actual forces |
| scalable / scalability | describe what scales and to what |
| compelling | say why it compels |
| unprecedented | name the precedent it breaks, or cut |
| exceptional / exceptionally | cite what makes it an exception |
| remarkable / remarkably | say what's worth remarking on |
| sophisticated | describe the sophistication |
| instrumental | say what role it played |
| world-class / best-in-class | cite a benchmark |
| valuable · various · vast · key · essential · vital · fundamental · notable · noteworthy · substantial | replace with the specific |

## The 2026 plain-word layer

This is the layer most published lists miss, because the register flipped. GPT-4-era slop was Latinate and ornate. GPT-5-era slop is short, plain, and Anglo-Saxon — which makes it much harder to blacklist, because every one of these is ordinary English.

**Flag by collocation, not by the bare word:**

| Word | Slop collocation | Why |
|---|---|---|
| quietly | quietly building, quietly dominating, quiet confidence, quiet rebellion | the flagship 2026 tell |
| matters | why it matters, this matters because, what matters is | formulaic importance-assertion |
| real | real growth, real value, real utility, the real question | unearned intensifier implying everything else is fake |
| actual / genuine / true | actual revenue, genuine utility, true product-market fit | same move, noun-modifier form |
| earn | earn trust, earn attention, earn the right to | abstraction attached to a transactional verb |
| the work | do the work, the work compounds | vague virtue-signalling |
| land | the point lands, it landed heavy | |
| shift / shape / hold / pull / compound / signal | the shift, shape the outcome, holds up, pulls forward, compounds over time | |
| stark / clean / sharp | a stark contrast, a clean answer, a sharp take | |
| honestly / "Honestly?" | as a standalone opener before an ordinary point | theatrical setup with nothing behind it |
| built different | | |

**Carve-out — named contrast.** If the sentence explicitly names what the fake version is, leave it. "Real on-chain settlement, not bridged IOUs" and "actual revenue from paying customers, not grants" are honest contrastive writing. The tell is the *unsaid* contrast.

## Model fingerprints

### ChatGPT / GPT

Tells skew **lexical and ornamental**. Look first at the word list, em-dash rate, and tricolons.

- Highest measured em-dash rate: **10.62 per 1,000 words** (GPT-4.1), vs a human mean of 3.23. Under explicit prohibition it still emitted 3.86/1k. OpenAI patched this in GPT-5.1 (Nov 2025), so newer output may be clean here while everything else still reads as GPT.
- The classic set: delve, tapestry, realm, testament, intricate, pivotal, crucial, vibrant, showcasing, underscoring, meticulously, groundbreaking.
- Era timeline, useful for dating a draft:
  - **GPT-4 (2023–mid 2024):** decorative abstractions — delve, tapestry, testament, vibrant, intricate, interplay
  - **GPT-4o (mid 2024–mid 2025):** corporate participial openers and gerunds — align with, bolster, fostering, highlighting, showcasing, underscoring
  - **GPT-5 (mid 2025 on):** conversational softening, staccato fragments, colon reveals ("Here's the thing:"), the plain-word layer above
- Openers: "In today's fast-paced world", "Let's dive in", "Picture this", rhetorical questions.
- 2026 additions: therapist mode — "You're not alone", "You're not broken", "That's completely valid", "Take a breath". OpenAI's own GPT-5.3 system card names "Stop. Take a breath." as targeted behaviour.
- Sycophancy rate measured at 56.7%.

### Gemini

Tells skew **organizational**. Vocabulary is the weak signal here; structure is the strong one. One vendor reports 61% detection driven by rigid organization rather than word choice.

- **List-first cognition.** Bullets and numbered lists even when the prompt didn't ask. Every bullet follows `**Bolded lead-in:** explanation`.
- High heading density, bold subheadings, abundant white space. Gemini describes its own default as "Optimized Standard English": modular organization with bolded headers, and "you shouldn't notice my writing style."
- Rigid claim–evidence–conclusion paragraph template, identical across sections.
- **The mandatory next-step closer.** Its system prompt instructs it to suggest a next step. This is the single most Gemini-specific structural tell.
- Comparison tables as a default output shape.
- Balance scaffolding: "on one hand… on the other hand", repeatedly, without committing.
- Plain-register nouns over technical synonyms ("high blood sugar" where GPT writes "elevated blood glucose levels"). Negation-first bigrams ("is not a") measured as distinctive.
- Openers: "Of course!", "Here's a breakdown", prompt restatement. Closers: "In essence", "Ultimately".
- **Highest measured sycophancy: 62.5%** — and it flatters as epistemic milestone ("You are having the exact realization that every great product founder has"), often paired with self-abasement.
- Lowest em-dash rate of the three: 3.53/1k. Do not treat em dashes as a Gemini tell.
- Creative-writing habits reported by testers: adjective-stacking ("Large, bare feet. Slick, wet grass."), computational metaphors for emotion ("her brain short-circuits"), recycled names (Kaelen, Elara).

### Claude

Tells skew **epistemic and rhetorical**. Look first at hedge density, reframing, and warm-collegial address.

- **Vendor-confirmed.** Anthropic's own leaked system prompt states: *"Claude avoids saying 'genuinely', 'honestly', or 'straightforward'."* You don't ban what the model doesn't overuse. This is the highest-confidence lexical datum available for any model.
- **"You're absolutely right"** — the best-documented Claude catchphrase of the era, with a filed GitHub issue and press coverage. Fires even when the user made no claim.
- Openers: "Here's the thing:", "Here's what's interesting", "Let me be direct", "The honest answer is", "The reality is", "That's a great question".
- Hedging cluster, Claude's most distinctive signal vs GPT: "It's worth noting", "I should note", "That said", "To be clear", "Generally speaking", "While it's true that", "There's genuine disagreement here".
- **Query reframing** — recasting the user's question before answering: "It's worth distinguishing between two things that often get conflated", "There are actually two different questions embedded in this", "The question assumes Y, but that framing may not quite capture".
- Closers: "Would that be helpful?", "Want me to dig deeper?" — both explicitly banned in the Opus 5 system prompt, confirming they are a default.
- Idiosyncratic vocabulary: `load-bearing` (metaphorical), `belt and suspenders`, `smoking gun`, `the unlock`, `substantive`, `calibrated`, `sharp` ("a sharp observation").
- **Invented labels** as a hybrid tell: abstract problem-noun (paradox, trap, creep, divide, vacuum, inversion) bolted to a domain word — "the supervision paradox", "the acceleration trap", "workload creep" — used as if established terminology.
- Em dashes at 9.09/1k, placed **mid-sentence** for additive qualification rather than at clause-ends for drama.
- **Moving target.** Anthropic has been suppressing headers/bullets/emoji since Sonnet 4.5. So 2026 Claude output is more likely dense prose, no emoji, no asterisk emotes, warm tone, heavy hedging, mid-sentence em dashes, and inline lists phrased "some things include: x, y, and z" — which is itself a fingerprint, and different from 2024-era header-and-bullet Claude.
- Because bullets are suppressed, Claude drifts into **listicle in a trench coat**: "The first wall is… The second wall is… The third wall is…"

### Carve-out for `load-bearing`

Only the hyphenated compound is a tell. "The load bearing down on the bridge" is ordinary English. And `load-bearing` before a literal structural noun (wall, beam, column, joist, truss, footing, slab, stud, lintel, girder, capacity), optionally with one material adjective between, is standard building terminology — do not flag. Abstract-capable nouns (structure, element, frame, foundation) are excluded on purpose, so "the load-bearing structure of his argument" still flags.
