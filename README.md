## Using These Skills

Use the folder form when you want to inspect or edit the skill. Use the `.zip` file when your skill environment expects packaged imports. The zip files are intentionally stored inside their respective skill folders so each skill can be published or shared independently.

Each skill is generalized for public use and should avoid private workspace names, personal identifiers, and company-specific workflow assumptions.
